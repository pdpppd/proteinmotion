# Continuous feature tour

The homepage film is one **100.5-second continuous scene**. Calmodulin stays on screen through the early demonstrations, morphs into troponin C, and that same troponin C model carries the remaining features. Caption changes never reset the protein or camera. Both the master and the web preview run at **60 fps**.

[Watch the film](https://pdpppd.github.io/proteinmotion/gallery/#showcase) · [Download the scene script](feature_showcase.py) · [Source and input files on GitHub](https://github.com/pdpppd/proteinmotion/blob/main/examples/feature_showcase.py)

## Render the same film

Use the repository checkout so the included structures and fixtures are available. This example uses the optional MD reader:

```bash
python -m pip install -e '.[md]'
proteinmotion render examples/feature_showcase.py FeatureShowcase \
  --fps 60 -o proteinmotion-showcase.mp4
```

`FeatureShowcase` is an ordinary `ProteinScene` with sequential `play()` calls and the standard deterministic `seek()`. There is one camera and two molecular objects. The target passed to `BackboneMorph` is used directly for the hydrogen-bond, ruler and electrostatics sections; it is never reloaded or recentered. `Focus`, `Representation`, `Colorize`, `SetOpacity`, `Write` and `Unwrite` preserve the preceding scene state.

Use `scene.chapter_manifest()` for exact chapter timings. The source exposes the camera margins, residue delays, representation transitions and line styles. Every frame, including the titles and transitions, is generated by ProteinMotion.

## Data and interpretation

- The starting model is calmodulin **1CLL**. [**1CFC**](https://www.rcsb.org/structure/1CFC) supplies 25 deposited calcium-free calmodulin NMR conformers. All **1,130 protein heavy atoms** in the 1CLL display topology map by exact atom identity to 1CFC and are aligned on common Cαs. The six nonprotein atoms absent from 1CFC are hidden during playback. The display retains its original topology and secondary-structure assignments.
- The XTC fixture contains all 25 mapped conformers. The film uses only states **1–3**, with 3.5 seconds per inter-state transition. NMR conformers are **not a physical time series**, and this XTC example is **not an MD simulation**. Eased coordinate bridges enter and leave the ensemble without a model cut.
- Run `from examples.feature_showcase import prepare_inputs; prepare_inputs()` to regenerate the PDB/XTC files and charge array. The explicit procedural deformation is also illustrative.
- The **1CLL→1NCX** morph uses the included contact-map correspondence. Its bounded matching search does not establish a global optimum, and the animation is not a physical folding pathway. See [matching methods](morphing.md).
- Troponin C's hydrogen bonds are detected using N···O ≤ 3.5 Å and N–H···O ≥ 150°. The angle uses **inferred backbone amide H**, and the drawn line connects the measured donor N and acceptor O. These are contacts from the deposited structure, not the separate ideal-helix fixture.
- The imported 1NCX charge array contains **illustrative formal side-chain charges**, not experimentally measured or force-field-assigned partial charges. Screened-Coulomb parameters are dielectric 80 and screening length 8 Å. The contact energy is an approximation under those settings.

The master is **1920×1080 at 60 fps**, rendered through Metal with 4× MSAA and VideoToolbox encoding. The homepage/gallery preview is **1280×720 at 60 fps**, with muted playback, standard video controls, and respect for reduced-motion preferences on the homepage.
