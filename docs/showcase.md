# Complete feature tour

The homepage film brings ProteinMotion's main visual capabilities into one **66.2-second, ten-chapter showcase**. Every frame is generated by the package: molecular geometry, camera motion, text, highlights, lines and transitions.

[Watch the film](https://pdpppd.github.io/proteinmotion/gallery/#showcase) · [Download the scene script](feature_showcase.py) · [Source and input files on GitHub](https://github.com/pdpppd/proteinmotion/blob/main/examples/feature_showcase.py)

## Render the same film

Use the repository checkout so the included structures and helper scene are available. This example uses the optional MD reader:

```bash
python -m pip install -e '.[md]'
proteinmotion render examples/feature_showcase.py FeatureShowcase \
  --fps 60 -o proteinmotion-showcase.mp4
```

`FeatureShowcase` is a seekable composition of ten ordinary `ProteinScene` classes. Each chapter can also be rendered separately using its class name, for example:

```bash
proteinmotion render examples/feature_showcase.py ContactMorph \
  --fps 60 -o contact-morph.mp4
```

Use `scene.chapter_manifest()` for exact chapter timings. The source keeps each scene's animation controls visible, including residue delays, focus margins, representation transitions and line styles. No separate video editor is required to assemble the film.

## Data and interpretation

- Ubiquitin uses deposited **2K39** NMR coordinates. The film plays states 1–25. The XTC fixture stores all 116 aligned deposited conformers and exercises `Trajectory.from_mdanalysis`; it is **not an MD simulation or physical time series**.
- The XTC/PDB files and atom-ordered charge array can be regenerated with `from examples.feature_showcase import prepare_inputs; prepare_inputs()`. The charge array contains **illustrative formal side-chain charges**, not experimentally measured or force-field-assigned partial charges. Screened-Coulomb parameters are dielectric 80 and screening length 8 Å.
- The deformation is authored for illustration. The alpha helix is the same explicit-H ideal geometry used in the [helix diagnostic](alpha-helix.md).
- The **1CLL→1NCX** morph uses the included contact-map correspondence and a configurable error bound. The bounded matching search does not establish a global optimum, and the animation is not a physical folding pathway. See [matching methods](morphing.md).
- The large complex is deposited **1AON**, with actual chains and atoms rather than replicated geometry.

The master is **1920×1080 at 60 fps**, rendered through Metal with 4× MSAA and VideoToolbox encoding. The homepage/gallery preview is **1280×720 at 30 fps**, with muted playback, standard video controls, and respect for reduced-motion preferences on the homepage.
